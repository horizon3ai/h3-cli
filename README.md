# h3-cli: CLI tool for the Horizon3 API

h3-cli is a convenient command-line interface for the Horizon3 API, providing programmatic access to NodeZero — schedule autonomous pentests, run NodeZero, monitor pentest status, and retrieve reports.

## 📖 Documentation

Full documentation for h3-cli — installation, getting started, authentication & profiles, running pentests, scheduling, NodeZero Runners, and the GraphQL API — is maintained on the official Horizon3 docsite:

**➡️ https://docs.horizon3.ai/cli/**

## Installation

Follow the official install instructions here: **https://docs.horizon3.ai/cli/getting_started/setup_cli/**

> ⚠️ **Installing via `git clone` of this repository is deprecated.** Please install h3-cli using the official instructions on the docsite linked above.
